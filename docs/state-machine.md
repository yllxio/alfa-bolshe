# Диаграмма состояний заявки

Диаграмма отражает ветвления клиентской демо-логики из `app.js`. Некоторые промежуточные шаги отображаются как `stage`, другие — как строковый `status`; это следует учитывать при изменении логики.

```mermaid
stateDiagram-v2
    [*] --> Черновик
    Черновик --> Отправлена: отправка клиентом
    Отправлена --> Проверка: обработка
    Проверка --> На_рассмотрении: модельные проверки
    На_рассмотрении --> Требуются_сведения: запрос сотрудника
    Требуются_сведения --> Повторная_проверка: загрузка документа
    Повторная_проверка --> На_рассмотрении: повторные проверки
    На_рассмотрении --> Предложены_условия: контрпредложение
    Предложены_условия --> На_рассмотрении: клиент принял
    Предложены_условия --> Предложение_отклонено: клиент отклонил
    На_рассмотрении --> Отказано: отказ сотрудника
    На_рассмотрении --> Одобрена: решение сотрудника
    Одобрена --> Оформление: начало оформления
    Оформление --> Готово_к_выдаче: демо-подписание
    Готово_к_выдаче --> Завершена: симуляция выдачи
    Отправлена --> Отозвана: клиент отозвал
    На_рассмотрении --> Отозвана: клиент отозвал
    Отказано --> [*]
    Отозвана --> [*]
    Завершена --> [*]
```

**Проверки решения:** для демонстрационного одобрения требуется согласие, выполненные синтетические проверки, подтверждение полноты документов, DSCR не ниже заданного порога 1,3 и соответствие числовым ограничениям выбранного аннуитетного продукта. Для нового незарегистрированного бизнеса предусмотрена блокировка одобрения.

**Ограничение:** система не реализует полноценный workflow engine, банковские maker-checker полномочия или серверную проверку переходов; переходы выполняет пользовательский JavaScript с сохранением синтетической заявки.
