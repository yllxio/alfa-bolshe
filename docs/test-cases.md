# Приёмочные и негативные тесты

## Автоматические

Запустить `python -m unittest discover -s tests -v` из корня. Проверяют формат ИНН, доступность синтетического реестра, 404 для неизвестного ИНН, JSON-обмен заявками, работоспособность сервера и ограничения на запросы.

## Ручной end-to-end

| ID | Действие | Ожидаемый результат |
| -- | -- | -- |
| E2E-01 | Создать вымышленную компанию, выбрать цель, рассчитать кредит, отправить заявку | Заявка видна в «Мои заявки» и очереди сотрудника |
| E2E-02 | Переключиться на сотрудника, открыть досье, выполнить модельные проверки | Результаты проверок отображаются, скоринг рассчитан |
| E2E-03 | Вкладка сотрудника «Документы»: добавить синтетические образцы, подтвердить полноту | Статус документов становится подтверждённым |
| E2E-04 | Менеджер одобряет корректную тестовую заявку | Клиент видит одобрение и переход к оформлению |
| E2E-05 | Клиент выполняет модельное подписание и выдачу | Итоговый статус «Завершена», история сохранена |
| E2E-06 | Менеджер предлагает новую сумму или срок | Клиент видит альтернативные условия и может принять/отклонить |
| E2E-07 | Менеджер запрашивает данные | Клиент видит задачу и может добавить документ |
| E2E-08 | Менеджер отказывает в заявке | Клиент видит отказ, история доступна |
| E2E-09 | Открыть два браузера на одном сервере, создать заявку в одном | Заявка появляется в другом после обновления/периодического опроса |
| NEG-01 | Ввести ИНН с неверной контрольной цифрой | Поиск отклонён до обращения к синтетическому реестру |
| NEG-02 | Ввести корректный, но отсутствующий в синтетических записях ИНН | Понятное сообщение об отсутствии данных и возможность ручного ввода |
| NEG-03 | Не подтвердить согласие | Обязательная модельная проверка не может считаться завершённой |
| NEG-04 | DSCR ниже порога и попытка одобрить | Объяснение причины блокировки; решение не записывается как одобренное |
| NEG-05 | Подписать или выдать до одобрения | Недопустимый переход не выполняется |
| NEG-06 | Загрузить слишком большой документ | Файл отклонён с сообщением о размере |
| NEG-07 | Отключить сервер после открытия клиента | Изменения сохраняются локально; отсутствие серверной синхронизации не маскируется как подтверждённое |

## Необходимые ручные проверки перед дедлайном

Docker сборка и запуск на обычном ПК, визуальная проверка в Chrome/Edge, переход между ролями в двух браузерах, правильность версий и обязательные технические артефакты, приглашение жюри в приватный репозиторий, фиксация commit SHA / tag.
